# 排口污染负荷离线复核台

澄川水务集团某污水厂排口的 **COD、氨氮、流量** 记录离线复核工具。断网环境可完整运行：
接入账与文件指纹、点位/设备实例、校准系数与状态有效期、片段编织与来源链、
自然日/月污染负荷与不确定范围、覆盖率与申报资格、迟到读数的锁定窗口复算候选。

本迭代新增 **工艺段平衡分析**：针对「进出水日负荷差异持续偏大」的归因需求，
按边界登记（进出水/回流/排泥/反冲洗/液位）把水量、无反应示踪量与可去除的
COD/氨氮分开；滞后匹配器建立进出水可达时间关系；平衡求解器分别给出水量闭合、
观测去除范围与不可解释残差；不确定度库保存仪表精度、共用校准来源与可接受
调整范围；归因台把结果交给工艺人员复核。两条路径并存：**误差传播**（每项测量
按误差范围直接传播，给出保证不越界的残差区间，资料不足时区间可能宽到无法排序）
与**受约束测量协调**（仅水量与示踪量在已知误差和相关关系下求最可能调整值）。
任何路径都不把 COD/氨氮的正常去除调成测量误差。

技术栈：**React 19 + TypeScript 5.9 + IndexedDB(idb) + WebWorker + Vite 7**。
所有重计算在 Worker 内完成，主线程只读写本地库与渲染；数据不出本机。

## 5. 计算口径（与引擎一致）

- 时间轴：`alignedAt = sampledAt + clockOffsetMs`，自然日按 Asia/Shanghai（UTC+8）。
- 片段边界：自然日端点、仪表实例/绑定交接、校准生效、状态切换、采样空档端点。
- 状态：仅 `OK` 可积分；`FLUSH/CALIB/BYPASS/FAULT` 整段排除并保留状态 ID。
- 采样空档：同一实例相邻有效读数间隔 > `nominal × 2.5`；空档自「上一读数 + 一个标称间隔」
  起算。段端最多保持一个标称间隔，不跨校准系数插值。
- 负荷：`∫ c(t)·q(t) dt / 3.6e6`（mg/L × m³/h × 秒 → kg）。
- 不确定范围：逐片段相对不确定度平方和开方 × `k`（默认 2）；重采样路线额外叠加
  梯形法解析误差界 `|c′q′|h³/6`。
- 覆盖/资格：覆盖率 = 有效积分秒 / 86,400；低于申报线 15pp 以上判不可申报。

### 两条积分路线

| | 逐有效片段积分（默认） | 经误差界验证的重采样积分 |
| --- | --- | --- |
| 局部证据 | 每个片段保留读数/校准/状态/文件 | 保留边界，片段内网格化 |
| 窄事件 | 40 s 冲击边界精确到读数时刻 | 需斜率上界 + 细分，否则会漏检 |
| 汇总成本 | 片段与结点多，查询较重 | 网格单元轻，便于跨层聚合 |
| 证明责任 | 无需额外证明 | 必须证明负荷范围、峰值、阈值穿越不变 |

核验阈值（`src/domain/engine.ts`）：负荷相对偏差 ≤0.5%，1h 峰值窗口中心偏移
≤ max(30 s, 1 网格)，阈值穿越并集对称差 ≤2 s，网格细分后无未决单元。

### 工艺段平衡分析口径（`src/domain/balance/`）

- **边界登记**：每个单元登记进出水、回流、排泥、反冲洗与液位；支路有效期
  [effectiveFrom, effectiveTo) 半开，今天确认的停用支路不改写过去的平衡。
- **三类对象分开**：水量、无反应示踪量（守恒）、COD/氨氮（可去除）。
  回流为内部循环，不计入主线闭合；回流泵切换按事件拆腿。
- **滞后匹配**：进水事件的可达时间带 = 事件时刻 + 全厂滞后带；出水事件落在带内
  且同向才允许配对；进水升高尚未到达可达时间带时保持在途，绝不强行配对。
- **路径 A（误差传播）**：每项测量按 1σ × k=2 直接传播，给出保证不越界的
  水量/负荷残差区间；缺测时段用登记估计补入区间并单独标注。
- **路径 B（受约束测量协调）**：仅水量与示踪量参与，min Σ(Δx/σ)²，
  协方差按共用校准组构造；调整量受证书边界约束，触及边界即钳制，
  仍无法闭合的部分保留为不可协调残差。
- **去除范围**：COD/氨氮的去除只依据曝气、污泥排放、投药、溶解氧等工艺记录
  与去除参数台账形成范围；观测超出支持的部分保留为不可解释残差，
  任何路径都不得把正常去除调成测量误差。
- **版本规则**：分析版本创建后不可改写；补传流量缩窄已审核残差时生成新版本
  （LATE_DATA），前版保持 REVIEWED；复核只追加归因结论与附注。

## 6. 申报与迟到复算

1. 「覆盖与资格」出具申报 → 生成 `FILED` 版本；截止接收时刻默认取该点位当日数据集的
   最大 `receivedAt`（样例为 2026-11-19 07:20），并锁定来源窗口、
   来源读数 ID 快照与来源文件指纹。
2. 「复算候选」导入迟到补录 → 读取落在锁定窗口内且 `receivedAt > 截止` 的读数。
3. 生成候选：只把迟到读数并入重算，原申报版本**不做任何修改**（`declarationOverwritten: false`），
   候选保存 `baseline` / `recomputed` / `diff` 与受影响片段。
4. 人工填写复核附注并标记 `REVIEWED`；是否作为下一版申报依据由人工决定。

平衡分析同理但按版本链管理：「平衡分析」页生成版本（不可改写）→「归因复核」页
复核（OPEN → REVIEWED）→「导入补传流量」后系统自动比较残差区间宽度，
显著缩窄时生成新版本（`LATE_DATA`，`supersedesId` 指向前版），前版保持
`REVIEWED` 原状；今天确认的停用支路（如 S-BYP 2026-11-20 起停用）只影响
生效日之后的新分析，不改写历史版本。

## 8. 已知边界

- 样例覆盖 2026-11-18 单日；月度页会明确显示「有数据 1 天 / 缺 29 天」，不补零。
- 时钟校正量来自设备台账的固定值；时钟漂移本身未建模，但偏移不确定度计入区间说明。
- 流量与浓度读数均取自一个排口的同一时刻对齐序列；跨厂站对比仅做展示，不合并负荷。
- 本工具不替代法定监测数据有效性判定，只提供可追溯的复核证据与缺口量化。
- 平衡分析的前一日在途量无数据，按 0 处理并在注意事项披露；U1/U4 无液位计，
  其存量变化按 0 处理（同样披露）。
- 去除范围依赖去除参数台账的登记区间（如氧转移效率 0.28–0.42），区间本身较宽时
  不可解释残差的上界也会偏宽——这是诚实的区间语义，而非额外假设。
- 路径 B 的协方差仅覆盖共用校准组内相关；组间相关与系统偏差未建模，
  触及证书边界的部分一律保留为不可协调残差，交由人工复核。
